# 09 — Herramientas de IA

## Qué hay disponible en Fedora

| Herramienta | Estado en Fedora |
|-------------|------------------|
| **Claude Code** (CLI) | Soportado. Instalador nativo, sin Node |
| **OpenCode** (CLI) | Soportado. Script oficial |
| **DeepSeek** | No es un programa: es una API. Se usa desde OpenCode o Claude Code |
| **Claude Desktop** | **Sin versión oficial para Fedora.** La beta de Linux es solo Debian/Ubuntu ([doc oficial](https://code.claude.com/docs/en/desktop-linux): "Fedora and RHEL: only Debian-based distributions are supported today"). Alternativa: claude.ai en el navegador |

Verifica el estado de Claude Desktop en el sitio de Anthropic antes de buscar versiones no oficiales; las de terceros no tienen soporte ni garantías.

## Pasos

### 1. Claude Code
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
Instalador oficial: pone el binario en `~/.local/bin/claude` y se auto-actualiza. No requiere root ni Node.

Alternativa oficial: repo `dnf` de Claude Code ([setup](https://code.claude.com/docs/en/setup#install-with-linux-package-managers)). No se auto-actualiza: `sudo dnf upgrade claude-code`.

Verifica que `~/.local/bin` esté en el PATH:
```bash
echo $PATH
```

Primer uso (abre el login en el navegador):
```bash
claude
```

Diagnóstico si algo falla:
```bash
claude doctor
```

### 2. OpenCode
```bash
curl -fsSL https://opencode.ai/install | bash
```
Instala el binario y lo agrega al PATH (reabre la terminal).

```bash
opencode --version
```

Fuente: [opencode.ai/docs](https://opencode.ai/docs/providers/). Ojo: existe otro proyecto con nombre parecido (`opencode-ai/opencode`); el de esta guía es el de **opencode.ai**.

### 3. DeepSeek con OpenCode (lo más simple)
1. Crea una API key en la consola de DeepSeek.
2. Abre `opencode` en tu proyecto.
3. Ejecuta `/connect`, busca **DeepSeek** y pega la key.
4. Ejecuta `/models` y elige un modelo DeepSeek.

### 4. DeepSeek con Claude Code (opcional)
DeepSeek ofrece un endpoint compatible con la API de Anthropic. Se configura con variables de entorno; el mapeo de modelos lo hace DeepSeek (`claude-opus*` → `deepseek-v4-pro`, `claude-sonnet*`/`claude-haiku*` → `deepseek-flash`).

Guarda tu key como variable en `~/.bashrc` (nunca en un repositorio):
```bash
echo 'export DEEPSEEK_API_KEY="tu-key"' >> ~/.bashrc
```

Crea un alias para no pisar tu login normal de Claude:
```bash
echo "alias claude-ds='ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic ANTHROPIC_API_KEY=\"\$DEEPSEEK_API_KEY\" claude'" >> ~/.bashrc
```
`claude` sigue usando Anthropic; `claude-ds` usa DeepSeek.

Revisa la guía oficial "Integrate with Claude Code" de [DeepSeek](https://api-docs.deepseek.com/guides/anthropic_api) por si el nombre de las variables cambió.

**Límites conocidos de la API compatible:** se ignoran `cache_control`, `citations` y `thinking.budget_tokens`; no soporta bloques `document`. Puede haber diferencias de comportamiento frente a Claude.

**Privacidad:** tu código y prompts viajan a los servidores del proveedor. Para código de trabajo confidencial, revisa la política de tu empresa antes de usar DeepSeek.

### 5. Modelos locales (opcional)
Tu RTX 4060 tiene 8 GB de VRAM: sirve para modelos pequeños (hasta ~8B). Para probar, Ollama es lo más simple, pero no es imprescindible. No lo incluí en el flujo principal para no sumar complejidad.

```bash
claude --version
```
```bash
opencode --version
```
```bash
echo $DEEPSEEK_API_KEY | wc -c
```
Debe ser mayor que 1 (confirma que la variable existe sin imprimir la key).
